# 🛡️ PassiveRecon - Comprehensive Passive Security Scanner

A **non-intrusive**, **passive** security reconnaissance tool that performs comprehensive security analysis of any website without causing harm or triggering DDoS protections.

**No API keys required. No active exploitation. Just clone and run.**

## ✨ Features

| Module | Description |
|--------|-------------|
| **HTTP Header Security** | Analyzes 11+ security headers (HSTS, CSP, X-Frame-Options, etc.) |
| **SSL/TLS Analysis** | Certificate validation, TLS version, cipher strength |
| **Content Security Policy** | Full CSP parsing, unsafe directive detection |
| **Cookie Security** | Secure, HttpOnly, SameSite flags analysis |
| **Technology Detection** | CMS, frameworks, CDN, versions (WordPress, Cloudflare, React, etc.) |
| **GDPR Compliance** | Cookie consent, privacy policy, tracker analysis |
| **PCI DSS Compliance** | Payment security requirements check |
| **Information Leakage** | API keys, admin panels, sensitive files, tokens |
| **OWASP Top 10** | Passive indicators for all OWASP categories |
| **External Content** | Third-party resources, SRI, mixed content |
| **DNSSEC** | DNS security, SPF, DMARC, CAA records |
| **Scraping Protection** | Rate limiting, CAPTCHA, WAF detection |
| **Robots & Sitemap** | robots.txt analysis, sensitive path
